# CDP Debug（WebView 调试）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Embed cdp-debug's WebView-debugging capability natively in ADB GUI: a new "CDP 调试" nav page that, given a selected device, one-click probes the `webview_devtools_remote_*` socket, forwards `tcp:9222`, connects the Chrome DevTools Protocol over websocket, and renders Console + Network + Eval + Reload in Compose — no external node bridge or browser HTML page.

**Architecture:** New `:core` I/O seam `CdpTransport` (duplex JSON over ws — `AdbStream` is one-way line text and can't serve CDP). `CdpEventParser` is a pure function (TDD, real-recorded fixtures). `CdpController` (modeled on `LogcatController`: long-lived job + reconnect loop + ring buffer + Mutex) owns the transport + event→StateFlow dispatch + request/response correlation. `KtorCdpTransport` (`:desktop/platform`, ktor-client-cio + ktor-client-websockets) is the actual. `CdpDebugViewModel` is thin over the controller; `CdpDebugScreen` is the page.

**Tech Stack:** Kotlin 2.1.20, Compose Multiplatform 1.7.3, kotlinx-coroutines 1.9.0, kotlinx-serialization-json 1.x, ktor-client-cio + ktor-client-websockets (NEW), JDK 21, kotlin.test + kotlinx-coroutines-test + app.cash.turbine. Gradle 8.11 wrapper.

**Spec:** `docs/superpowers/specs/2026-08-31-cdp-debug-design.md` — the spec is the authority this plan argues from.

## Global Constraints

- **JDK 21**; Gradle wrapper 8.11 (Tencent mirror `distributionUrl` + Aliyun Maven mirrors already configured — keep them).
- **`:core` must not depend on Compose/`java.awt`/`javax.swing`/ktor.** `CdpTransport` is an interface; `CdpController`/`CdpEventParser`/domain models are pure Kotlin. ktor ONLY in `:desktop/platform`.
- **UI red line #2:** `CdpDebugViewModel` (`:desktop`) injects `CdpController` (`:core`) only — never `CommandRunner`/ktor/ws directly. `CdpController` (`:core`) injects `CommandRunner` for `webviewSocket`/`forward`/`removeForward` (core→core, mirrors `LogcatController`).
- **Package roots:** `com.adbgui.core.*` / `com.adbgui.desktop.*`.
- **TDD on `:core`**: failing test → verify fails → minimal impl → verify passes → commit. CDP fixtures under `core/src/test/resources/fixtures/cdp/`, **real-recorded** (tech-debt rule #4 — see Task 2 for the required recording; do NOT hand-write CDP frame fixtures).
- **Commits:** Conventional Commits (`feat(core):` / `feat(desktop):` / `fix(...)`). One commit per task (or per logical step within a task).
- **Dispatcher injection (tech-debt rule #1):** `CdpController` I/O (ws + adb) runs on the injected `CoroutineScope`; no hardcoded `Dispatchers.IO`. Tests pass `Unconfined`/`runTest` scope. `KtorCdpTransport`'s ktor `HttpClient` uses its own dispatcher (ktor-internal, fine).
- **No dead code (tech-debt rule #2):** no "might use later" CDP domain placeholders; no unused params.
- **Cross-thread mutable state (tech-debt rule #3):** `CdpController`'s transport handle + `pending` map must be `@Volatile` or `Mutex`-guarded; ring buffer writes `Mutex`-serialized (mirror `LogcatController`).
- **Plan-level rulings:**
  - **R1 (real CDP fixtures, user-gated):** per the user's explicit choice, `CdpEventParser` tests use REAL recorded CDP frames, not hand-constructed JSON. The recording (Task 2) needs a connected device with the target WebView app on screen + the (already-merged) port-forwarding page to forward `tcp:9222` + a node capture script (Task 1 produces it). Task 2 is **user-gated** and produces `fixtures/cdp/*.ndjson` + the `cat /proc/net/unix` fixture. Task 3 (parser TDD) is **blocked** until Task 2 completes. This is the plan's one user-gate (mirrors port-forwarding's Task 7 gate, but earlier — real frames are needed for parser TDD). If executing via SDD and no device is available, Task 1 runs, then execution pauses at Task 2 until the user records.
  - **R2 (forward ownership):** `CdpController` owns the forward it creates in one-click mode — `start(serial)` calls `commands.forward(...)`, `stop()` calls `commands.removeForward(...)`. Manual mode (`connectManual(port)`) does NOT touch forward (user-managed). The VM never calls forward.
  - **R3 (request/response correlation):** CDP frames with an `id` field are responses to prior requests; `CdpController` routes them via a `pending: Map<Int, Completer>` (mirror cdp-ui.html's `cdpSend`/`pending`). Frames with a `method` field are events → `CdpEventParser`. `CdpController` uses a monotonic `id` counter for its own requests (`evaluate`/`reload`/`getResponseBody`/`Target.getTargets`/`*.enable`).
  - **R4 (target selection):** `CdpController` auto-picks the first `type=="page"` target from `Target.getTargets`; the VM exposes a target dropdown whose selection triggers reconnect to a different page ws. No multi-browser-ws fanout in v1.
- **Reused seams:** `AdbProcessRunner` + `FakeAdbProcessRunner` (v1) for adb; `CommandRunner.runCmd`/`runShellCmd` for `webviewSocket`; `ForwardSpec`/`ForwardEndpointType` (port-forwarding feature, merged) for `commands.forward`/`removeForward`. `LogcatController` is the structural template for `CdpController`.
- **Existing signatures (don't change):** `CommandRunner(adb, runner, logger, scope, server)`; `runShellCmd(serial, cmd): String` (sanitizes pty control chars — use it for `cat /proc/net/unix`); `commands.forward(serial, local: ForwardSpec, remote: ForwardSpec)`; `commands.removeForward(serial, local: ForwardSpec)`.

```kotlin
package com.adbgui.core.domain

/** Console severity for a CDP console entry. Maps Runtime.consoleAPICalled `type` and Log.entryAdded `level`. */
enum class CdpLevel { LOG, DEBUG, INFO, WARNING, ERROR }

/** One console line from the device WebView (Runtime.consoleAPICalled / Runtime.exceptionThrown / Log.entryAdded). */
data class CdpConsoleEntry(
    val level: CdpLevel,
    val text: String,
    val source: String,        // "console-api" / "exception" / "log-entry" — which CDP event produced it
    val url: String?,
    val lineNumber: Int?,
)

enum class CdpNetState { SENT, RESPONSE, DONE, FAILED }

/** One network request, merged across Network.requestWillBeSent/responseReceived/loadingFinished/Failed by `requestId`. */
data class CdpNetworkRequest(
    val requestId: String,
    val method: String,
    val url: String,
    val state: CdpNetState,
    val status: Int?,
    val mime: String?,
    val error: String?,
)

/** A page target from Target.getTargets. */
data class CdpTarget(val targetId: String, val type: String, val title: String, val url: String)

enum class CdpConnectionState { DISCONNECTED, CONNECTING, CONNECTED, RECONNECTING, FAILED }

/** Result of Runtime.evaluate — either a value or a JS exception (one non-null). */
data class CdpEvalResult(val value: String?, val exception: String?) {
    init {
        require((value != null) xor (exception != null)) { "exactly one of value/exception must be non-null" }
    }
}

/** Parsed CDP event (frames with a `method` field). Responses (frames with an `id` field) are routed by CdpController, not parsed here. */
sealed class CdpEvent {
    data class ConsoleAdd(val entry: CdpConsoleEntry) : CdpEvent()
    data class NetRequest(val req: CdpNetworkRequest) : CdpEvent()
    data class NetResponse(val requestId: String, val status: Int, val mime: String?) : CdpEvent()
    data class NetDone(val requestId: String, val ok: Boolean, val error: String?) : CdpEvent()
}
```

```js
// cdp-capture.js — dev-only ws capture for recording real CDP frames into NDJSON fixtures.
// Run: node cdp-capture.js <outFile> <pageTargetId>
// Prereq: forward tcp:9222 to the device's webview socket first (use the app's Port Forwarding page).
// Requires: `ws` npm package (npm install ws) — or use `websocat` if available.

const fs = require('fs');
const outFile = process.argv[2];
const targetId = process.argv[3];
if (!outFile || !targetId) { console.error('usage: node cdp-capture.js <outFile> <pageTargetId>'); process.exit(1); }
fs.writeFileSync(outFile, ''); // truncate
const ws = new WebSocket('ws://localhost:9222/devtools/page/' + targetId);
ws.on('open', () => {
  ['Runtime.enable','Page.enable','Network.enable','Log.enable'].forEach((m,i) =>
    ws.send(JSON.stringify({id: i+1, method: m})));
  console.error('capturing to ' + outFile + ' — exercise the webview, Ctrl+C to stop');
});
ws.on('message', (frame) => fs.appendFileSync(outFile, frame.toString() + '\n'));
ws.on('error', (e) => { console.error('ws error:', e.message); process.exit(2); });
ws.on('close', () => console.error('ws closed'));
```

```kotlin
package com.adbgui.core.adb

import com.adbgui.core.domain.CdpConsoleEntry
import com.adbgui.core.domain.CdpEvent
import com.adbgui.core.domain.CdpLevel
import com.adbgui.core.domain.CdpNetState
import com.adbgui.core.domain.CdpNetworkRequest
import kotlinx.serialization.json.JsonElement
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.contentOrNull
import kotlinx.serialization.json.jsonArray
import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive

/** Pure parser for CDP event frames (those with a `method` field). Response frames (with an `id`)
 *  are routed by CdpController, not here. Returns null for unknown methods or malformed payloads —
 *  never throws (CdpController logs unknown methods at DEBUG per the "don't silently swallow" rule). */
object CdpEventParser {

    fun parseEvent(method: String, params: JsonObject): CdpEvent? {
        return when (method) {
            "Runtime.consoleAPICalled" -> parseConsoleApi(params)
            "Runtime.exceptionThrown" -> parseException(params)
            "Log.entryAdded" -> parseLogEntry(params)
            "Network.requestWillBeSent" -> parseNetRequest(params)
            "Network.responseReceived" -> parseNetResponse(params)
            "Network.loadingFinished" -> CdpEvent.NetDone(reqId(params), true, null)
            "Network.loadingFailed" -> CdpEvent.NetDone(reqId(params), false, params["errorText"]?.str())
            else -> null
        }
    }

    private fun parseConsoleApi(p: JsonObject): CdpEvent.ConsoleAdd? {
        val type = p["type"]?.str() ?: return null
        val args = p["args"]?.jsonArray() ?: return CdpEvent.ConsoleAdd(
            CdpConsoleEntry(level = mapLevel(type), text = "", source = "console-api", url = null, lineNumber = null))
        val text = args.joinToString(" ") { argText(it) }
        return CdpEvent.ConsoleAdd(CdpConsoleEntry(mapLevel(type), text, "console-api", null, null))
    }

    private fun parseException(p: JsonObject): CdpEvent.ConsoleAdd? {
        val det = p["exceptionDetails"]?.jsonObject() ?: return null
        val text = (det["text"]?.str().orEmpty() + " " +
            (det["exception"]?.jsonObject()?.get("description")?.str().orEmpty())).trim()
        return CdpEvent.ConsoleAdd(CdpConsoleEntry(CdpLevel.ERROR, text, "exception",
            det["url"]?.str(), (det["lineNumber"]?.jsonPrimitive?.contentOrNull)?.toIntOrNull()))
    }

    private fun parseLogEntry(p: JsonObject): CdpEvent.ConsoleAdd? {
        val e = p["entry"]?.jsonObject() ?: return null
        val level = mapLevel(e["level"]?.str() ?: "log")
        val text = e["text"]?.str() ?: ""
        return CdpEvent.ConsoleAdd(CdpConsoleEntry(level, text, "log-entry",
            e["url"]?.str(), (e["lineNumber"]?.jsonPrimitive?.contentOrNull)?.toIntOrNull()))
    }

    private fun parseNetRequest(p: JsonObject): CdpEvent.NetRequest? {
        val req = p["request"]?.jsonObject() ?: return null
        val id = p["requestId"]?.str() ?: return null
        return CdpEvent.NetRequest(CdpNetworkRequest(
            requestId = id,
            method = req["method"]?.str() ?: "",
            url = req["url"]?.str() ?: "",
            state = CdpNetState.SENT, status = null, mime = null, error = null,
        ))
    }

    private fun parseNetResponse(p: JsonObject): CdpEvent.NetResponse? {
        val resp = p["response"]?.jsonObject() ?: return null
        val id = p["requestId"]?.str() ?: return null
        val status = resp["status"]?.jsonPrimitive?.contentOrNull?.toIntOrNull() ?: 0
        val mime = resp["mimeType"]?.str()
        return CdpEvent.NetResponse(id, status, mime)
    }

    private fun mapLevel(s: String): CdpLevel = when (s.lowercase()) {
        "log" -> CdpLevel.LOG
        "debug", "verbose" -> CdpLevel.DEBUG
        "info" -> CdpLevel.INFO
        "warning", "warn" -> CdpLevel.WARNING
        "error" -> CdpLevel.ERROR
        else -> CdpLevel.LOG
    }

    private fun argText(e: JsonElement?): String =
        e?.jsonObject?.let { it["value"]?.str() ?: it["description"]?.str() ?: it["unserializableValue"]?.str() } ?: "?"

    private fun JsonObject.str(): String? = this.jsonPrimitive.contentOrNull
    private fun reqId(p: JsonObject): String = p["requestId"]?.str() ?: ""
}
```

```kotlin
package com.adbgui.core.device

import com.adbgui.core.adb.CdpConnectionException
import com.adbgui.core.adb.CdpEventParser
import com.adbgui.core.adb.CdpTransport
import com.adbgui.core.adb.CommandRunner
import com.adbgui.core.domain.CdpConnectionState
import com.adbgui.core.domain.CdpConsoleEntry

import com.adbgui.core.domain.CdpEvent
import com.adbgui.core.domain.CdpNetworkRequest
import com.adbgui.core.domain.CdpNetState
import com.adbgui.core.domain.CdpTarget
import com.adbgui.core.domain.ForwardEndpointType
import com.adbgui.core.domain.ForwardSpec
import com.adbgui.core.log.Logger
import kotlinx.coroutines.Completer
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Job
import kotlinx.coroutines.delay
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.collect
import kotlinx.coroutines.launch
import kotlinx.serialization.json.Json
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive
import kotlinx.serialization.json.contentOrNull
import kotlinx.sync.Mutex
import java.util.concurrent.atomic.AtomicInteger

class CdpController(
    private val transport: CdpTransport,
    private val commands: CommandRunner,
    private val logger: Logger,
    private val scope: CoroutineScope,
) {
    private val json = Json { ignoreUnknownKeys = true }

    private val _console = MutableStateFlow<List<CdpConsoleEntry>>(emptyList())
    val consoleEntries: StateFlow<List<CdpConsoleEntry>> = _console.asStateFlow()
    private val _net = MutableStateFlow<List<CdpNetworkRequest>>(emptyList())
    val networkRequests: StateFlow<List<CdpNetworkRequest>> = _net.asStateFlow()
    private val _targets = MutableStateFlow<List<CdpTarget>>(emptyList())
    val targets: StateFlow<List<CdpTarget>> = _targets.asStateFlow()
    val state: StateFlow<CdpConnectionState> = transport.state
    private val _error = MutableStateFlow<String?>(null)
    val error: StateFlow<String?> = _error.asStateFlow()

    private val pending = mutableMapOf<Int, Completer<JsonObject>>()  // guarded by pendingMutex
    private val pendingMutex = Mutex()
    private val nextId = AtomicInteger(1)

    private var runJob: Job? = null
    @Volatile private var ownsForward = false        // one-click mode → stop() removes it
    @Volatile private var currentSerial: String? = null
    @Volatile private var browserConnected = false

    /** One-click: probe webview socket → forward 9222 → connect browser ws → pick page → enable domains. */
    suspend fun start(serial: String) {
        currentSerial = serial
        val socket = commands.webviewSocket(serial)
            ?: throw CdpConnectionException("无 webview socket — 目标应用需在前台运行且含 WebView")
        commands.forward(serial,
            ForwardSpec(ForwardEndpointType.TCP, "9222"),
            ForwardSpec(ForwardEndpointType.LOCALABSTRACT, socket))
        ownsForward = true
        connectAndRun()
    }

    /** Manual: skip forward, connect to ws://localhost:<port>/devtools/browser directly. */
    suspend fun connectManual(port: Int) {
        ownsForward = false
        currentSerial = null
        connectAndRun(portOverride = port)
    }

    private suspend fun connectAndRun(portOverride: Int? = null) {
        val browserUrl = "ws://localhost:${portOverride ?: 9222}/devtools/browser"
        runJob?.cancel()
        runJob = scope.launch {
            try {
                transport.connect(browserUrl)
                browserConnected = true
                val targetsResp = cdpSend("Target.getTargets", emptyMap()).await()
                val pages = targetsResp["targetInfos"]?.jsonArray()?.mapNotNull {
                    val o = it.jsonObject
                    if (o["type"]?.str() == "page") CdpTarget(
                        o["targetId"]?.str() ?: "", "page",
                        o["title"]?.str() ?: "", o["url"]?.str() ?: "")
                    else null
                } ?: emptyList()
                _targets.value = pages
                val page = pages.firstOrNull()
                    ?: throw CdpConnectionException("没有 page target（应用没在前台？）")
                // Connect to the page ws (transport reconnects to the page URL).
                transport.connect("ws://localhost:${portOverride ?: 9222}/devtools/page/${page.targetId}")
                listOf("Runtime.enable", "Page.enable", "Network.enable", "Log.enable").forEach { cdpSend(it, emptyMap()) }
                runLoop()
            } catch (e: CdpConnectionException) {
                _error.value = e.message
            }
        }
    }

    private suspend fun runLoop() {
        // Reconnect loop with exponential backoff (mirror LogcatController): 1s→…→30s cap, 3 fails → FAILED.
        var failures = 0
        while (true) {
            try {
                transport.incoming.collect { frame -> handleFrame(frame) }
            } catch (e: Throwable) {
                logger.debug("[cdp] runLoop error: ${e.message}")
            }
            failures++
            if (failures > 3) { _error.value = "正在重连（多次失败）"; }
            delay(minOf(30_000L, 1000L * (1L shl minOf(failures, 5))))
            runCatching { transport.connect("ws://localhost:9222/devtools/page/${_targets.value.firstOrNull()?.targetId ?: ""}") }
        }
    }

    private fun handleFrame(frame: String) {
        val obj = runCatching { json.parseToJsonElement(frame).jsonObject }.getOrNull() ?: return
        val id = obj["id"]?.jsonPrimitive?.contentOrNull?.toIntOrNull()
        if (id != null) {
            // Response — complete the pending request.
            scope.launch { pendingMutex.withLock { pending.remove(id) }?.complete(obj) }
            return
        }
        val method = obj["method"]?.str() ?: return
        val params = obj["params"]?.jsonObject ?: JsonObject(emptyMap())
        val event = CdpEventParser.parseEvent(method, params)
        if (event == null) {
            logger.debug("[cdp] unknown CDP method: $method")
            return
        }
        applyEvent(event)
    }

    private fun applyEvent(e: CdpEvent) {
        when (e) {
            is CdpEvent.ConsoleAdd -> scope.launch {
                pendingMutex.withLock {
                    val cur = _console.value
                    _console.value = (cur + e.entry).takeLast(10000)
                }
            }
            is CdpEvent.NetRequest -> scope.launch {
                pendingMutex.withLock { _net.value = _net.value + e.req }
            }
            is CdpEvent.NetResponse -> scope.launch {
                pendingMutex.withLock {
                    _net.value = _net.value.map { if (it.requestId == e.requestId)
                        it.copy(status = e.status, mime = e.mime, state = CdpNetState.RESPONSE) else it }
                }
            }
            is CdpEvent.NetDone -> scope.launch {
                pendingMutex.withLock {
                    _net.value = _net.value.map { if (it.requestId == e.requestId)
                        it.copy(state = if (e.ok) CdpNetState.DONE else CdpNetState.FAILED, error = e.error) else it }
                }
            }
        }
    }

    /** Send a CDP request, await its response by id. */
    private fun cdpSend(method: String, params: Map<String, Any?>): Completer<JsonObject> {
        val id = nextId.getAndIncrement()
        val req = buildString {
            append("{\"id\":$id,\"method\":\"$method\"")
            if (params.isNotEmpty()) append(",\"params\":${json.encodeToString(JsonObject.serializer(), params.toJsonObject())}")
            append("}")
        }
        val completer = Completer<JsonObject>()
        scope.launch { pendingMutex.withLock { pending[id] = completer }; transport.send(req) }
        return completer
    }

    suspend fun evaluate(expr: String, frame: String?): CdpEvalResult {
        val params = if (frame == null) mapOf("expression" to expr, "returnByValue" to true, "awaitPromise" to true)
            else mapOf("expression" to "($frame).eval(${Json.encodeToString(kotlinx.serialization.builtins.serializer<String>(), expr)})", "returnByValue" to true)
        val resp = cdpSend("Runtime.evaluate", params).await()
        val result = resp["result"]?.jsonObject()?.get("result")?.jsonObject()
        val exc = resp["result"]?.jsonObject()?.get("exceptionDetails")
        return if (exc != null) CdpEvalResult(null, exc.jsonObject()["exception"]?.jsonObject()?.get("description")?.str() ?: "JS exception")
        else CdpEvalResult(result?.get("value")?.str() ?: result?.get("description")?.str(), null)
    }

    suspend fun reload() { cdpSend("Page.reload", emptyMap()).await() }

    suspend fun getResponseBody(requestId: String): String? {
        val resp = cdpSend("Network.getResponseBody", mapOf("requestId" to requestId)).await()
        return resp["body"]?.str()
    }

    fun stop() {
        runJob?.cancel()
        runJob = null
        transport.close()
        browserConnected = false
        val serial = currentSerial
        if (ownsForward && serial != null) {
            scope.launch { runCatching { commands.removeForward(serial, ForwardSpec(ForwardEndpointType.TCP, "9222")) } }
        }
        ownsForward = false
    }
}

// Helper: Map<String, Any?> → JsonObject (kotlinx.serialization doesn't have a one-liner).
private fun Map<String, Any?>.toJsonObject(): JsonObject {
    val map = this.entries.associate { (k, v) ->
        val el = when (v) {
            is String -> kotlinx.serialization.json.JsonPrimitive(v)
            is Boolean -> kotlinx.serialization.json.JsonPrimitive(v)
            is Number -> kotlinx.serialization.json.JsonPrimitive(v)
            else -> kotlinx.serialization.json.JsonNull
        }
        k to el
    }
    @Suppress("UNCHECKED_CAST")
    return JsonObject(map)
}

// String helper for JsonObject field access (duplicated locally to keep the file self-contained; OR reuse a shared helper).
private fun JsonObject.str(): String? = this.jsonPrimitive.contentOrNull
```

```kotlin
package com.adbgui.desktop.platform

import com.adbgui.core.adb.CdpConnectionException
import com.adbgui.core.adb.CdpTransport
import com.adbgui.core.domain.CdpConnectionState
import io.ktor.client.HttpClient
import io.ktor.client.engine.cio.CIO
import io.ktor.client.plugins.websocket.WebSockets
import io.ktor.client.plugins.websocket.webSocket
import io.ktor.websocket.Frame
import io.ktor.websocket.readText
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Job
import kotlinx.coroutines.channels.Channel
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.receiveAsFlow
import kotlinx.coroutines.launch

/** Production CdpTransport — ktor-client-cio + ktor-client-websockets actual. Connects ws://localhost:<port>/...,
 *  bridges ktor's session incoming/outgoing to the CdpTransport interface. */
class KtorCdpTransport(private val scope: CoroutineScope) : CdpTransport {
    private val client = HttpClient(CIO) { install(WebSockets) }
    private val _state = MutableStateFlow(CdpConnectionState.DISCONNECTED)
    override val state: StateFlow<CdpConnectionState> = _state.asStateFlow()
    private var sessionOut: Channel<String>? = null
    private var incomingCh = Channel<String>(Channel.UNLIMITED)
    override val incoming: Flow<String> = incomingCh.receiveAsFlow()
    private var sessionJob: Job? = null
    @Volatile private var currentUrl: String? = null

    override suspend fun connect(url: String) {
        currentUrl = url
        _state.value = CdpConnectionState.CONNECTING
        sessionJob?.cancel()
        incomingCh.close(); incomingCh = Channel(Channel.UNLIMITED)
        sessionOut = Channel(Channel.UNLIMITED)
        sessionJob = scope.launch {
            try {
                client.webSocket(urlString = url) {
                    _state.value = CdpConnectionState.CONNECTED
                    val outgoing = sessionOut!!
                    // Pump outgoing → session.send
                    val sendJob = launch { for (msg in outgoing) send(Frame.Text(msg)) }
                    // Pump session.incoming → our incomingCh
                    try {
                        for (frame in incoming) {
                            if (frame is Frame.Text) incomingCh.send(frame.readText())
                        }
                    } finally { sendJob.cancel() }
                }
            } catch (e: Throwable) {
                _state.value = CdpConnectionState.FAILED
                throw CdpConnectionException("ws connect failed: ${e.message}")
            } finally {
                _state.value = CdpConnectionState.DISCONNECTED
            }
        }
    }

    override suspend fun send(json: String) { sessionOut?.send(json) }

    override fun close() {
        sessionJob?.cancel(); sessionJob = null
        incomingCh.close()
        _state.value = CdpConnectionState.DISCONNECTED
    }
}
```
